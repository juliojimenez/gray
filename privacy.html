Privacy, in plain words

Effective November 14, 2026

The short version: Gray doesn't know who you are, and likes it that way. No accounts, no ads, no cookies, no data sold — ever. Course progress stays in your own browser, and what you (or your kid) type in the course never leaves your device. The one exception is a grown-up who buys the optional subscription: that purchase goes through Stripe, and it's explained below.

What stays on your device

The browser course saves a few things in your browser's local storage so it can pick up where you left off:

  • Course progress — which section and lesson you're on, per language.
  • Your program — the my_first_program file built during graduation.
  • Small technical notes — a cached copy of the visitor counter and a one-time flag the page uses to set itself up.
  • Subscription key — only if a grown-up has subscribed: the key that unlocks the paid paths.

Progress and programs are never transmitted anywhere. The subscription key is the one thing that travels: it's sent to Gray's own server when a paid path loads, to check the subscription (more on that below). All of it belongs to you: the Start over button on the play page erases the course data, and clearing your browser's site data removes everything.

Counting visits

We count visits with GoatCounter, chosen because it uses no cookies and no persistent identifiers. When a page loads, GoatCounter's server briefly processes a standard web request (page visited, referrer, browser type, screen size, and country-level location) to add +1 to an aggregate count. It does not build profiles of visitors, and neither do we — the homepage number is the whole point. See GoatCounter's own privacy documentation for details.

The downloadable course

gray.py and gray.lua run entirely on your own computer, offline. The only network use is a quick check of gray.academy at startup for a newer version of the course — a normal web request that sends nothing about you and fails silently without internet. Setting GRAY_NO_UPDATE=1 turns it off entirely. There is no telemetry: the course never reports what anyone types, learns, or builds.

Playing in the browser

The browser course runs Python and Lua inside your browser — code you type is executed on your device, not on a server. To make that work, the page loads the language engines from the jsDelivr open-source CDN, whose servers see a standard web request when the files download. What you type into the course is never sent to us, to jsDelivr, or to anyone else.

Buying the subscription

The paid learning paths are optional, and buying them is a grown-up's job. Checkout happens on Stripe's pages, not ours. Stripe collects the buyer's name, email, billing address and card details, takes the payment and sends the receipts, and it (or its Link service) may appear as the seller on the receipt. Gray never sees card numbers. What Stripe does with that information is covered by Stripe's privacy policy.

Through Stripe we can see who has subscribed (their name, email and billing details, though never a full card number) and whether the subscription is still running. We use that to provide the subscription and to answer email about it, and for nothing else.

When checkout finishes, Stripe sends the buyer back to the play page with a reference to that checkout, and the page hands it to Gray's paths server once to receive the subscription key. From then on, whenever a paid path loads, the page sends the key to that server, which asks Stripe whether the subscription is active and then sends back the course. The server runs on Cloudflare, which sees a standard web request, as any host does. It doesn't keep a list of keys or of who asked for what. It only remembers for ten minutes that a key was good, so it doesn't have to ask Stripe again on every visit.

A kid playing a paid path is never asked for a name, an email or anything else personal. The key is all the page needs.

Made for kids

Gray is built for children, so it's designed to collect nothing personal from them: no names, no emails, no accounts, no chat, and nothing typed in a lesson ever leaves the device. The only time anyone's details are involved is when a grown-up subscribes, and that happens on Stripe's checkout. Parents: the Foundations course and the page that runs it are open source, so you can read every line of what your kid is running.
